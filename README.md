
# CodeAlpha Task Automation

## About the Project

This project is a simple Python automation script developed as part of the CodeAlpha Python Programming Internship.

The program automatically moves all JPG image files from a source folder to a destination folder.

## Features

- Automatically detects JPG files.
- Creates the destination folder if it does not exist.
- Moves JPG images using Python.
- Supports both uppercase and lowercase JPG extensions.
- Displays a success message after moving each file.

## Technologies Used

- Python
- OS Module
- Shutil Module

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Add JPG images to the images folder.
4. Open the terminal.
5. Run the following command:

```bash
py task_automation.py
```

## Expected Output

```text

photo2.jpg moved successfully!
photo3.jpg moved successfully!

JPG file organization completed!
```
